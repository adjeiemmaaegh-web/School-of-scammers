# Legacy reports (archived)

These ~70 `*_INCREMENT_REPORT.md`, `*_SOURCE_MANIFEST.json`, and `*.txt` log files were produced by the previous developer and cluttered the repository root. They are **kept here for history** (not deleted) but moved out of the root so the project is legible.

They describe the step-by-step construction of the salvaged simulation engine (`src/engineering/*`, `src/core/`, `src/engine/`). They are **not** the current product direction — see `docs/product/PRD.md` (v3) for that.
