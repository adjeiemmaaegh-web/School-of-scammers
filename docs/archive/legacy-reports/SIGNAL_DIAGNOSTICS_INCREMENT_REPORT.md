# PLC Skills Lab — Scan-based diagnostic alarms

Added a pure scan-history rule evaluator, five configurable diagnostic rule definitions, dwell thresholds, active/cleared episodes, deterministic CSV export, a workbench UI, and six Vitest test definitions. No backend.

This is an educational, sampled-time diagnostic approximation. Thresholds require a duration of matching recorded samples; recorder gaps and history eviction limit detection. Browser build and full Vitest execution require dependencies.
