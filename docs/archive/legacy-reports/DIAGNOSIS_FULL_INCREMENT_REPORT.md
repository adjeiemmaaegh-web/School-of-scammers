# Fault diagnosis laboratory — consolidated increment

Ten selectable deterministic troubleshooting scenarios spanning motor starter, PLC sensor wiring, and conveyor equipment. Each includes a symptom, live PLC observations, scan evidence, isolation-gated simulated repair, cause selection, and state-verified grading. Integrated into the existing engineering workbench. No backend.

## Known limitations

Educational simplified electrical and physical models. The UI's repair control is a guided repair, not manual wire-level replacement. A learner can view scenario hints. Full application build and browser QA remain pending if dependencies are unavailable.
