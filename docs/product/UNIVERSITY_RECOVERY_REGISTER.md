# University recovery mission: traceability register (28 findings)

Owner mission: resolve the 28 simulation findings from the university evaluation by real engineering. This register is the single honest record of where each finding stands. It is updated with every stage; a row is only marked DONE when functioning behaviour exists **and** automated acceptance evidence is listed. Interface labels, static meshes and documentation never count.

**Status vocabulary:** `DONE` (behaviour + evidence), `PARTIAL` (some real capability exists, the finding is not fully met), `NOT STARTED` (no relevant capability found in source), `AUDITED` (source inspected this session, no change made yet).

**Baseline audited from source on 2026-11-20** (branch `engineering/r13-university-recovery`, stacked on `engineering/r12-reference-layout`): 54 placeable kinds (26 with a plant model), 21 scenes, Ladder/ST/FBD, six PLCs, 60-component / 250-wire / 60-body caps (`src/sim/panels.ts`, `src/plant/world/types.ts`), 32 rungs / 48 tags (`docs/product/PLC_SUBSET.md`), physics in `src/plant/world/physics.ts` whose own header states: *"Deterministic teaching physics: carry, axis-aligned contact/queue, gravity, simplified push and stack. NO unconstrained rigid-body/contact solver."* Several historical audits were therefore partly right (R01, R06, R08, R10) and partly outdated (R04, R05, R12, R27 already have some equipment).
