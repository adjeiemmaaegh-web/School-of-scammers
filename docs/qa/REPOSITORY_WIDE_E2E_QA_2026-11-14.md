## 4. Coverage gaps / priority before product launch

1. **Critical commercial trust:** identity-proofed assessments, authenticated result integrity, anti-replay, disclosure/privacy and realistic cheating threat model require product owner authorization; base64 alone cannot establish scores.
2. **Critical industrial claims:** independent real PLC electrical observations, conveyor/stopper feedback measurement, human guarding/force assessment, and real physical camera/industrial control integration are not modeled equivalents.
3. **High user-device compatibility:** actual Windows 11 8GB CPU-only integrated-GPU WebGL, long sessions, thermal memory, mobile touch browsers, offline service worker upgrade and storage-eviction trials need owner-run hardware.
4. **High independent QA:** deterministic seeds and bad PLC controllers provide strong functional coverage but not exhaustive instruction/fault permutations; add property fuzzing of project import, mutation against safety-ish invariants, differential real hardware observations and multi-tab concurrent library write recovery.
5. **High deployment/data risk:** test configured CSP on the real hosting origin, assess HTTP caching/version rollout, IndexedDB/localStorage quotas, backup loss and multi-tab consistency; no SQL database exists.
6. **Dependencies/licenses:** verify exact current production npm advisories and tarball notices, browser automation toolchain and source assets; legally clear all direct/transitive licenses before commercial distribution.
7. **Accessibility/performance:** automated axe high-severity scan does not prove WCAG conformance; add screen-reader flows, keyboard-only operation, contrast audits and measured low-spec timing and 3D frame budgets.
